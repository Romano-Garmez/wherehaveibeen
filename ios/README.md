# WhereHaveIBeen iOS

Native SwiftUI viewer for the per-user endpoints on `https://mini.romangarms.com`.
See `../PRD.md` for the product and API contract.

## Build

The project file is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)
from `project.yml` and committed so Xcode opens it directly. After adding or
moving files, regenerate:

```
brew install xcodegen
xcodegen generate
```

Open `WhereHaveIBeen.xcodeproj`, set your signing team on the app target, and run
on a device or simulator. No third-party dependencies.

## Test

```
xcodebuild -project WhereHaveIBeen.xcodeproj -scheme WhereHaveIBeen \
  -destination 'platform=iOS Simulator,name=iPhone 17' build test
```

## Mock data

The `WhereHaveIBeen Mock` scheme launches with `--mock-api --mock-signed-in`,
which serves the fixtures in `WhereHaveIBeen/Resources/Fixtures/` through
`MockAPIClient` and skips sign-in. Drop `--mock-signed-in` to exercise the
sign-in form; the password `wrong` is rejected, anything else is accepted.
A refresh in mock mode answers `computing` once so the progress banner shows.

## Local API

Debug builds have a **Use local API** toggle in Settings that points the client
at `http://localhost:5002`; the ATS exception in `Info.plist` is scoped to
`localhost`.
